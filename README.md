# Meena Foods — Since 1942

> **A taste that began in 1942.** Artisanal bakery, rusks, breads, and buns made for everyday moments. Crafted with heritage pride in Kumudavalli, Bhimavaram, Andhra Pradesh.

---

## 🏛️ Website Experience Architecture

The website is structured as a continuous cinematic heritage journey across 8 modular sections:

- **Section 00 — Opening Experience**: Full-screen atmospheric brand video hero loop with centered editorial statement and scroll indicator.
- **Section 01 — The Brand (The Name On Every Pack)**: 2-second visual showcase slide rhythm with authentic packaging and 1942 watermark story.
- **Section 02 — The Meena Table**: Everyday moments across morning, tea time, and evening.
- **Section 03 — The Collection**: Clean 2×4 editorial product grid with interactive category filtering (All, Bread, Rusk, Bun) and detailed modal view.
- **Section 04 — The Making**: 3D photorealistic production journey from mix, knead, ferment, shape, bake to pack, featuring station controls and traveling progress line.
- **Section 05 — The Moments**: Cinematic video gallery with 4 real videos (`gallery1.mp4`–`gallery4.mp4`), side-by-side 16:9 layout, explore more reveal toggle, and video lightbox.
- **Section 06 — Visit Meena**: Physical destination section with 55/45 split, authentic imagery, and verified interactive actions (Call, WhatsApp, Email, Get Directions).
- **Section 07 — Final Memory & Footer**: Deep warm espresso ending with fine line-art table scene, animated rising steam, editorial statement, official logo anchor, and minimal functional footer.

## 🚀 Deployment (Vercel)

This is a modern static web application with vanilla JavaScript ES modules and responsive CSS.

### Deploying with Vercel:
1. Import this repository (`veerakumar978/meena-products`) in your [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./` (leave default).
4. Click **Deploy**.
